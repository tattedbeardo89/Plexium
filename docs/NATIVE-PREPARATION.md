# Native preparation evidence

The original network denial was resolved for the primary source hosts during this task. The official VLC archive was downloaded and validated against VideoLAN's published SHA-256 `e7cab503d1d7d5849b89d2cf0e1ee60d0ef6d012407791b644b9cfc0cc225fdf`. It is retained under `/workspace/plexium-work/dl`, with source under `/workspace/plexium-work/src`.

All 22 exact native dependency versions now have authoritative published digests in `ci/source-checksums.txt`, with sources recorded in `ci/source-checksum-provenance.json`. Most are from the verified VLC archive or pinned official VLC revisions; FreeType's upstream checksum is recorded by Buildroot and HarfBuzz's by the pinned Meson wrap database. NASM and zlib use other archive compression formats for the same versions so that the **published expected hashes** can be checked; expected hashes were not fabricated or changed to match downloads. zlib's compressed source is fetched from VideoLAN's official contrib mirror.

`tools/fetch-native-sources.py` verifies cached and freshly downloaded archives, keeps TLS enabled, restricts redirects to HTTPS and reports each independent network failure. A checksum mismatch is fatal; unverified files are never unpacked by the guarded dependency fetcher. FreeType's Savannah redirect is pinned to the mirror Savannah supplied, `ftp.cc.uoc.gr`, because its automatic mirror choice varies. That host was initially denied; the later request succeeded and its original expected checksum passed. All 22 source archives are now verified.

The pinned Arch base image was retrieved by digest. Package installation preserved repository signatures and TLS. The Dockerfile package step succeeded after allowing its downloader to read the public CA mount, but BuildKit then failed to prepare the WORKDIR filesystem layer (`invalid argument`). A directly launched container succeeded with the same pinned base and signed package recipe (`ci/prepare-container.sh`). No daemon/storage-driver changes were made.

The open PS5 payload SDK v0.42 archive passed the original fork's checksum verification. The installed SDK records b83202be73e930050e00de0f1b4d9ec46c0391bf. PS5_Vulkan's clean-room runtime was rebuilt twice byte-identically, and both expected raw/signed hashes passed. Signed runtime SHA-256: `e6ff45d16adf687855cc3b33b0c8a4132b6504360b221e0a34c7e99fb3ba0036`. This validates that runtime prerequisite, **not Plexium's executable**.

The prepared container image is saved locally under `/workspace/deps`, with a checksum, so a new task can restore it without relying on a live process or a transient Docker cache. `ci/start-native-container.sh` starts a fresh container with the current task's proxy variables and read-only CA mount. It checks the expected image ID. Toolchain setup is not a public application release.

Native GPU-driver compilation and target TLS libraries are prepared separately through `ci/bootstrap-native-runtime.sh` and `ci/bootstrap-native-deps.sh`. All target prerequisite recipes, static VLC and the final native application completed; exact final outcomes are recorded in VALIDATION.md and artifacts/logs. Source/native prerequisites stay outside the product checkout. The driver repository's active task concerns Dolphin/Vulkan probes; that is context only, and no such unrelated task or console deployment was undertaken.
